# V10 Phase 3 Setup

1. Deploy/run all previous V9 and V10 SQL migrations first.
2. In Supabase SQL Editor run `supabase/v10-phase3.sql`.
3. No additional environment variables are required.
4. Deploy the updated application.
5. Sign in, open **Teams**, create a squad, then add one of your own or a public shinobi.
6. Use **Rivals** to save a rivalry and **Matchups** to compare profiles.

Existing V9/V10 characters, quiz results, jutsu, missions, progression, credits and public profiles are preserved.
